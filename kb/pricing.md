# Paket Harga Nagara Digital Indonesia

## Paket Starter — Rp 2.500.000 / project
- Website 5 halaman
- Setup CRM dasar (Airtable)
- Blast WA 1x (maks 500 kontak)
- Support 30 hari

## Paket Professional — Rp 5.000.000 / bulan
- Website unlimited halaman + maintenance
- CRM penuh (kontak tidak terbatas)
- Blast WA + Email unlimited
- AI Chatbot basic
- Support prioritas

## Paket Enterprise — Rp 10.000.000 / bulan
- Semua fitur Professional
- AI Agent custom (dilatih dengan data klien)
- Dashboard command center internal
- Integrasi sistem existing (core banking, ERP)
- Dedicated account manager

## Catatan
- Harga bisa disesuaikan untuk BPR / institusi keuangan
- Tersedia uji coba gratis 14 hari untuk paket Professional
- Pembayaran bisa bulanan atau tahunan (diskon 20% untuk tahunan)
